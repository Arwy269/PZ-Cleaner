# assets —— 底图源图放这里（不进版本库）

网页底图是从**世界大地图**切出来的，那两张图太大（共 95 MB），不适合放进 git，
所以本目录在版本库里只有这份说明。要用完整清晰度的网页预览，请把源图放到这里：

| 文件名 | 是什么 | 哪来的 |
| --- | --- | --- |
| `Map.png` | 原版地图渲染（浅色、画风像游戏内的地图） | 做地图 mod 用的那份世界大图 |
| `world.png` | 地形渲染（深色、树林有质感） | 同上 |

**约定**：图内 **1 像素 = 1 世界格**，内容左上角就是世界坐标 `(0,0)`，内容区大小 `19797×15897`。
这个对应关系是配准验证过的（k=1.0000 像素/格、偏移 (0,0)），不是估的。

放好之后在仓库根目录执行：

```bash
pip install pillow

python tools/make_tiles.py                        # 切瓦片 → web/tiles/（约 25 MB，1677 块）
python tools/make_basemap.py --from-image assets/Map.png --width 8192   # 总览图 → web/map.jpg
```

想换成地形渲染版就把 `Map.png` 换成 `world.png`（坐标完全一致，直接换即可）。

> 只有 `Map.png`、没有源图也能用：网页会自动退回到 `web/map.jpg`；
> 如果连 `map.jpg` 都没有，预览页会提示"未找到 map.jpg"，但**清理功能本身不受影响**——
> 网页预览只是拿来核对的，删不删由 exe 决定。
