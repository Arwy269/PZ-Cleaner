僵毁区块清理器 v1.0.3
================================================

这是什么？
  删除僵尸毁灭工程 B42 服务器存档里【除安全屋以外】的所有区块文件，
  重启服务器后这些区域会按地图包重新生成（地形/建筑/战利品/丧尸），
  而玩家的安全屋、基地、箱子原样保留。

怎么用？（3 步）
  1. 先关闭僵尸毁灭工程服务器！（非常重要）
  2. 双击 区块清理器.exe，打开图形界面
  3. ① 选存档并点「分析」 → 核对数字 → ② 点「执行清理」，按提示输入确认词

界面上的东西
  存档路径    含 map\ 的那一层，就是 Saves\Multiplayer\<存档名>
              「自动查找」会扫 C:\Users\*\Zomboid\Saves
  安全屋外扩  安全屋四周额外保护多少格，默认 0
  备份目录    填了才备份（文件会移动到 该目录\存档名_时间戳\，可还原）；
              留空 = 不备份，删掉就找不回来了
  ① 分析     扫描区块、解析安全屋、算出留哪些删哪些，并生成网页预览数据
  ② 地图预览   地图直接嵌在程序窗口里（不弹浏览器），进去就是当前分析结果，不用找文件。
              紫=已有区块  绿=保留  红=将被删除  黄框=安全屋
              按住 Shift 拖拽可额外框选要保住的区域，点「保存到清理器」直接存回来，
              窗口那边自动重新分析。
              万一嵌入失败（系统缺 WebView2 运行时），会自动改用浏览器打开，功能一样。
  ② 执行清理  会要求手动输入确认词，然后才开始删

安全机制
  - 检测到服务器进程在运行 -> 直接拒绝执行
  - 一个安全屋都没解析到 -> 直接拒绝执行（防止删光全图）
  - 必须手动输入确认词才会真的开始删
  - 只删 map\<X>\<Y>.bin，map_meta.bin 等其它文件一律不碰

文件说明
  区块清理器.exe   主程序（图形界面）
  config.json      配置：包里的是一份默认值，可以先改好再启动；
                   跑过之后会自动记录上次的存档/缓冲/备份目录
  keep.json        可选：网页导出的额外保护区
  web\             网页预览（底图 map.jpg + 全分辨率瓦片 tiles\，约 28 MB）
                   想让地图看得最清楚，请把整个 web 文件夹跟 exe 放在一起

命令行模式（可选，需要装 Python）
  在源码目录执行：
    python pz_chunk_cleaner.py --dry              只分析不删除
    python pz_chunk_cleaner.py --list             列出所有安全屋
    python pz_chunk_cleaner.py --backup-dir "E:\PZ备份"
