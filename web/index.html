3) 视图

底图 map.jpg 与网页同目录，可自行替换。锚点是世界方格坐标， 换地图或加了地图包需要重新校准（现用底图：1 像素 = 1 世界格的原版地图渲染，已配准）。 网格只影响网格线，颜色叠加层最细按 1 个区块（8 格）统计。

4) 额外保护区（可选）

清理器只保护安全屋。想额外保住某个基地 / 公共仓库时： Shift + 拖拽 = 加一块保护区 Ctrl+Shift + 拖拽 = 减去一块 右键 框内 = 删掉该框 退格 = 撤销上一块
导出的 keep.json 放到 exe 同目录，清理器会自动读取。
